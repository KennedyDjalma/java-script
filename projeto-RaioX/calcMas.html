Informações:

Corpo ósseo = Com Bucky.
Extremidades = Sem Bucky.
Obs.: Se fizer extremidade no buck usa 0,5 no calculo do mAs. Estruturas superiores a 10cm usa-se:
mAs = (2 x E + CA) x C.M.M. Estruturas inferiores a 10cm usa-se: mAs = (2 x E + CF) x C.M.M.
Onde: CA = constante do aparelho. (Para descobrir a constante do aparelho basta diminuir todo o KV na mesa de comando. O KV mínimo é a constante do aparelho.) CF = constante do filme. (Para filmes de base verde a constante é 20 e para base azul a constante é 30.)
